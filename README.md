# Projekt Bramy 1 – STM32 Gate Controller

*Semestral university project developed in collaboration with a fellow student.*

---

## Overview

This repository contains the firmware for a **gate controller** built around an **STM32G0** microcontroller.  The gate operates in the classic **Warehamër style** (a simple, reliable open/close mechanism) and is driven by a motor that is precisely controlled using hardware timers and an encoder.

## Features

- **STM32G0** (STM32G031) MCU with HAL drivers
- **Encoder input** (TIM2) for accurate position feedback
- **PWM motor control** (TIM3) with forward, reverse, brake and stop modes
- **Timer‑based control loop** (TIM14) running at ~1 kHz
- Simple **PID controller** (currently commented out, ready for tuning)
- Configurable target positions (open/close) with a 5 s demo cycle

---

## Hardware

| Component | Description |
|-----------|-------------|
| MCU | **STM32G031** – Arm Cortex‑M0+, 64 KB flash, 16 KB RAM |
| Encoder | Quadrature encoder connected to TIM2 for position sensing |
| Motor driver | PWM output on TIM3 channels 1/2 drives an H‑bridge |
| Timer | TIM14 generates a periodic interrupt for the control loop |
| Power | 5 V supplied via the development board |

---

## Software Architecture

- **Core/** – Application code (`main.c`, `stm32g0xx_it.c`, etc.)
- **Drivers/** – CMSIS core files and the STM32 HAL library
- **CMake** – Out‑of‑source build system generated by STM32CubeMX
- **Projekt_bramy_1.ioc** – CubeMX project file defining peripherals and pinout

The firmware follows the standard STM32 HAL pattern:
1. System clock configuration (`SystemClock_Config`)
2. Peripheral initialization (`MX_TIM2_Init`, `MX_TIM3_Init`, `MX_TIM14_Init`, `MX_GPIO_Init`)
3. Encoder reading and PWM updating in the `HAL_TIM_PeriodElapsedCallback`
4. Main loop that sets target positions and handles higher‑level logic

## Build Instructions

```bash
# 1. Configure the build directory (once or after CMake changes)
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug

# 2. Build the firmware (uses Ninja under the hood)
cmake --build build

# 3. Flash the MCU (replace with your flashing tool if different)
st-flash write build/Debug/Projekt_bramy_1.elf 0x8000000
```

*Tip:* The generated `compile_commands.json` (`build/Debug/compile_commands.json`) can be used by clang‑d for IDE assistance.

---

## Usage

After flashing, the firmware runs an infinite loop that:
- Reads the encoder value from TIM2
- Moves the gate to a **target position** (currently 0 → 1 → 0) with a 5 second pause between moves
- Controls motor speed and direction via PWM on TIM3

To modify behavior, edit the target position logic in `main.c` and, if needed, enable and tune the PID block (lines 99‑115).
